Conexión al servidor

1
Crea una nueva Google Sheets.
El nombre puede ser cualquiera (ej. Bitácora)
2
Menú superior → Extensiones → Apps Script
3
Pega todo el contenido del archivo google_apps_script.js descargado → 💾 Guardar
4
Botón Implementar → Nueva implementación → Tipo: App web
Ejecutar como: Yo / Acceso: Cualquier persona → Implementar
5
Copia la URL de la app web y pégala abajo

La configuración se guarda en este dispositivo
